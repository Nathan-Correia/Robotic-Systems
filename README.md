# Robotic-Systems

Robotics-Systems is a repository to store the code for the exercises in CMPUT 412.

## Usage

### 1.

The relevant scripts for the assignment are contained in packages in the /packages subfolder.

### 2.

The scripts can be run using duckietown shell (dts) by following the duckumentation listed here
https://docs-old.duckietown.org/daffy/duckietown-robotics-development/out/connecting_operating_duckiebot.html
